# Evidence model

| Label | Meaning |
|---|---|
| ESTABLISHED | Definition, specified encoding or documented result under its stated hypotheses. |
| STRONGLY SUPPORTED | Convergent evidence supporting a conditional assessment. |
| PROJECT-REPRODUCED | Project code recalculated an explicitly specified model or arithmetic. |
| PLAUSIBLE | Argued extrapolation or inference. |
| SPECULATIVE | Proposed mechanism without sufficient validation. |
| UNKNOWN | Required evidence is absent; no defensible determination. |

ESTABLISHED does not mean perfectly secure. UNKNOWN does not mean insecure.

Evidence roles are PROJECT-DERIVED RESULT, EXTERNAL LITERATURE RESULT, INFERENCE and OPEN QUESTION. AUTHOR CLAIM remains attributed. Internal project files are not independent literature citations.
