# Classical and cross-cutting attack ledger

**Scope:** Every cost depends on the actual distribution and parameter set. “Unknown” is not a security margin. A generic work factor against vectorisation does not prove computational or decisional parallelisation hard.

| Attack | Applicable targets and method | Time / memory / parallelism | Precomputation and many-target issue | Current finding |
| --- | --- | --- | --- | --- |
| Meet-in-the-middle / collision | Split a bounded exponent vector or traverse two action walks until endpoints collide | For ideal uniform group size \(N\), generic collision on order \(\sqrt N\) evaluations and memory; distinguished-point variants change memory/time | base curve and relation tables can be reused, multi-target collisions may lower per-key marginal cost | parameter-specific entropy and distribution needed |
| Claw finding | Match two action representations or public targets | generic collision-scale classical baseline; exact exponents depend on walk distribution | tables across fixed base may amortize | distinguish from SIDH gluing |
| Relation lattice | Small prime ideal generators satisfy class-group relations; reduce or identify bounded exponent vectors | depends on computed class group and generator lattice, no universal exponent | heavy class-group computation can be offline | CSI-FiSh exploits class-group computations; exposure of extra hop curves may sharply weaken schemes |
| Ideal-class recovery | Recover ideal/action relating curves | meets action-specific vectorisation problem | common parameters can aid precomputation | CSIDH attack target; not automatically needed to compute parallelised secret |
| Endomorphism-ring recovery | Recover endomorphism information from supersingular curve, relevant to MIKE | no defensible universal concrete minimum for MIKE established here | fixed public base and many targets need re-analysis | root assumption in announced AIM proof is newer |
| Torsion / SIDH gluing | Use transported torsion point basis and known starting endomorphism to recover SIDH secret | SIKEp434 ~10 minutes / one CPU core reported | public auxiliary structure is the enabler | absent in plain CSIDH and 2024 MIKE public encoding; reassess any acceleration that exposes it |
| Special curves / weak keys | Degenerate automorphisms, invalid orientation, small walks, biased exponent vectors, relation-equivalent secrets | can be far below generic bound for a subpopulation | batch attackers can select weak public objects | rejection and statistical keygen analysis required |
| Invalid public object | Supply singular, wrong-field, nonsupersingular, wrong-orientation or off-domain curve; observe behavior | implementation dependent, potentially trivial oracle abuse | adaptive chosen ciphertexts make this acute | full validation before secret action and uniform failure behavior required |
| Fault / side channel | Disorientation faults, dummy-operation skipping, secret-dependent torsion points, cache/power | fault repetitions or traces, implementation dependent | exploitable in deployed device, outside generic model | published CTIDH fault attacks motivate dummy-free and intermediate validation |

For a secret vector \(e_i\in[-m_i,m_i]\), nominal entropy is at most \(\sum_i\log_2(2m_i+1)\); the image of the action and relation quotient, nonuniform sampling and rejection can reduce it. A uniform support of \(2^h\) gives only generic classical exhaustive \(2^h\) and Grover \(2^{h/2}\) oracle baselines; MITM can reduce further. Do not equate secret encoding bytes, class number or field bits with effective entropy. A concrete design must report histogram/min-entropy or sampler proof, relation lattice, weak-key fraction, public-key multiplicities and many-user success probability.

The 2026 [CRT-decomposed CSIDH proof proposal](https://arxiv.org/abs/2609.26258) reports that publication of CRT hop curves changes a classical key-recovery estimate from about \(2^{128.6}\) to \(2^{67.3}\) action evaluations for its CSIDH-512 experiment. This is a scheme-specific warning, not a general CSIDH attack. [2025 shifted-input study](https://eprint.iacr.org/2025/376.pdf) makes the corresponding quantum warning.

Primary sources: [Castryck–Decru](https://eprint.iacr.org/2022/975.pdf); [CSI-FiSh](https://eprint.iacr.org/2019/498.pdf); [disorientation faults](https://ir.cwi.nl/pub/33834); [hardened dCTIDH](https://arxiv.org/abs/2509.12877); [module action](https://eprint.iacr.org/2024/1556.pdf). Precise attack bounds for hypothetical MIKE KEMs remain open.
