# When should the project be reopened?

**Principle:** A trigger is evidence that could change a named gate, not permission to invent a candidate. Reassess attacks, bytes, proof, implementation and status at one identical parameter set.

| Trigger | Previous conclusion it could change | Required evidence |
|---|---|---|
| Independent MIKE classical/quantum cryptanalysis | Phase 4A unknown concrete margin | exact sampler, attack-resource vector, independent derivation/code and counteranalysis |
| Complete MIKE IND-CCA KEM specification | unknown complete PK+CT and CCA path | serialized objects, validation, ROM/QROM/model proof with loss, independent implementation |
| New group-action quantum algorithm or oracle | CSIDH size/MIKE security ledger | target-specific gates, depth, QRAM, qubits, classical preprocessing |
| Canonical DAWN paper and reference vectors | Phase 2C primary-source block | immutable hash/version, full algorithm, matched bytes, correctness and transform |
| Rigorous correlated DAWN DFR/independent attack | author's model qualification and size/security comparison | realistic per-key tail and same-distribution lattice/QROM analysis |
| BAT old/new full proof pair | unknown correction impact | exact changed lemma/game, assumptions, reduction loss and BAT-512 implication |
| BIKE-like rigorous decoder | Phase 3 secret-decoder obstacle | extreme per-key DFR theorem, reaction/CCA and performance at matched bytes |
| New lattice reduction or quantum ISD results | current numerical margins | same-instance, comparable memory and multi-target cost model |
| Independently verified McEliece structural attack | Classic McEliece security qualification | distinguish proven distinguisher, heuristic recovery and practical break |
| New average-case hardness problem | Phase 1 rejection of unsupported novelty | concrete public distribution, secret recovery, quantum study, CCA and full bytes |
| NIST standardization change | deployment-status statement | final standard text, parameters and errata; other schemes remain unvalidated |

Speed claims alone, zero failures in ordinary simulation, and a short public object without CT and CCA are insufficient triggers. The construction search remains closed under the present requirements.
